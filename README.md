# Кроссворд «Учёба и наука»

Интерактивный кроссворд по 20 английским словам из лексики о вузе, научной
работе и международном сотрудничестве. Вопросы — на русском, ответы
вписываются латиницей. Сайт полностью статический: без сборки, фреймворков
и внешних зависимостей.

## Запуск

Самый простой способ — открыть `index.html` в браузере (двойной щелчок).

Если браузер ограничивает сохранение прогресса для файлов `file://`,
запустите локальный сервер из папки проекта:

```bash
py -m http.server 8000
```

и откройте <http://localhost:8000>.

## Что умеет

- Сетка кроссворда с нумерацией и двумя списками вопросов.
- Переход по клику, стрелкам, Tab; повторный клик по клетке меняет направление.
- Проверка ответов: верные буквы подсвечиваются зелёным, ошибки — красным.
  Подсветка держится до исправления буквы или следующей проверки.
- Подсказка (одна буква), открытие текущего слова и показ всех ответов.
- Таймер, прогресс и автосохранение в `localStorage`.
- Адаптивная вёрстка, увеличение сетки (кнопки «−» и «+»), прокрутка сетки
  на узких экранах.
- Поздравление с конфетти после разгадывания.
- Печать: `Ctrl+P` — элементы управления и подсветка скрываются.

## Управление

| Действие | Результат |
| --- | --- |
| Клик по клетке | Выбрать слово; повторный клик — сменить направление |
| Буквы A–Z | Вписать букву и перейти к следующей клетке |
| Стрелки | Перемещение по сетке |
| Пробел | Сменить направление |
| Backspace | Стереть букву / вернуться назад |
| Tab / Shift+Tab | Следующее / предыдущее слово |
| Enter | Следующее слово |
| Home / End | Начало / конец текущего слова |
| Esc | Выйти из сетки (фокус на карточку вопроса) |
| Ctrl+V | Вставить слово по буквам |

Дефисы и пробелы в сетку не вписываются: `part-time` → `PARTTIME`.

## Структура

```
index.html                 страница
styles.css                 оформление и адаптивность
app.js                     логика кроссворда
puzzle.js                  раскладка и вопросы (генерируется)
tools/generate_crossword.py генератор раскладки
```

## Как изменить набор слов

1. Отредактируйте список `WORDS` в `tools/generate_crossword.py`
   (пары «ответ — вопрос», ответы латиницей без дефисов).
2. Запустите генератор:

   ```bash
   py tools/generate_crossword.py --seconds 12 --seed 7
   ```

   Скрипт соберёт связную сетку, выведет её статистику в консоль и
   перезапишет `puzzle.js`.
3. Проверьте `puzzle.js`: вопросы и номера слов должны соответствовать
   задуманному списку. При необходимости поменяйте `--seed` и запустите
   генератор ещё раз.

Генератор использует жадный поиск с возвратами и допускает пересечения
только по совпадающим буквам. Все слова размещаются в одной связной сетке.
